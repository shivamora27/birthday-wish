# 🎵 Audio Setup Instructions

The website is configured to play "Happy Birthday" song when the cake is cut!

## How to Add the Audio File

### Option 1: Use Your Own Audio File (Recommended)
1. Find or create a "Happy Birthday" audio file (MP3 format recommended)
2. Name it `happy-birthday.mp3`
3. Place it in the `/birthday-wish/` folder (same location as index.html)

### Option 2: Use a Free Online Source
You can download free Happy Birthday songs from:
- **YouTube Audio Library** (royalty-free music)
- **FreePD.com** (public domain music)
- **Bensound.com** (free with attribution)
- **Incompetech.com** (creative commons)

### Option 3: Record Your Own
1. Record yourself singing "Happy Birthday" on your phone
2. Transfer the file to your computer
3. Convert to MP3 if needed (use online converters like online-convert.com)
4. Rename to `happy-birthday.mp3`
5. Place in the birthday-wish folder

## File Format Support
The website supports both:
- `happy-birthday.mp3` (most common)
- `happy-birthday.ogg` (backup format)

## Testing the Audio
1. Make sure the audio file is in place
2. Open the website in your browser
3. Click "Cut the Cake!" button
4. The audio should play automatically

**Note:** Some browsers block autoplay audio. If it doesn't play, the user might need to interact with the page first (like clicking anywhere).

## Troubleshooting
- **Audio doesn't play?** Check if the filename matches exactly: `happy-birthday.mp3`
- **Wrong song playing?** Replace the file with the correct one
- **Volume too low?** Edit the audio file or increase system volume
- **Browser blocking?** Try a different browser (Chrome usually works best)
