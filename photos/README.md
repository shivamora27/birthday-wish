# Photos Folder

## Instructions

Place your photos in this folder with the following names:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

You can use JPG, PNG, or any other image format. Just make sure to update the file extensions in the `index.html` file if needed.

### Recommended Image Sizes
- Minimum: 800x600 pixels
- Recommended: 1200x900 pixels or higher
- Aspect Ratio: 4:3 or 16:9 works best

### Tips
- Use high-quality photos for best results
- The images will be automatically cropped to fit
- You can add more photos by duplicating the photo-card sections in index.html
- Edit the captions in index.html to personalize each photo
